# LinguaRust Desktop

Нативное десктопное окно для Windows на Rust + WebView2. Внутри работает та же
офлайн-версия сайта: карточки, словарь, чтение, грамматика, экзамен, тренажёр
письма и прогресс в `localStorage`.

## Что умеет оболочка

| Возможность | Как это выглядит для пользователя |
| --- | --- |
| Значок в трее | Меню из пяти пунктов, подпись «5 к повторению», клик открывает окно |
| Закрытие в трей | Кнопка ✕ прячет окно, приложение живёт в трее (переключается) |
| Резервные копии на диске | Прогресс автоматически дублируется в `%APPDATA%\LinguaRust\progress.json` |
| Восстановление | Пустое окно молча поднимает копию с диска; кнопка ♻️ — вручную |
| Экспорт в файл | Кнопка 💾 пишет `exports\linguarust-ГГГГ-ММ-ДД-ЧЧММСС.json` |
| Сохранение «как…» | Системный диалог выбора файла вместо папки `exports` |
| Открытие копии | Системный диалог: `.json` с прогрессом или `.csv` с карточками |
| Открыть папку данных | Кнопка 📂 открывает каталог в Проводнике |
| Автозапуск | Кнопка 🚀/🚫 пишет ключ в `HKCU\...\Run` с аргументом `--autostart` |
| Заголовок окна | Тёмный или светлый — как тема в приложении |
| Геометрия окна | Размер, позиция и развёрнутое состояние запоминаются |
| Командная палитра | `Ctrl+K` в окне: переходы по разделам и нативные действия |
| Фокус-сессия | Таймер 15/25/45 минут, перерыв 5 минут, +15 XP за подход, отсчёт в трее |
| Глобальные горячие клавиши | Работают, когда окно свёрнуто или не в фокусе |
| Импорт перетаскиванием | Файл `.json` или `.csv`, брошенный в окно, загружает прогресс |
| Печать и PDF | Системный диалог WebView2 с сохранением страницы в PDF |
| Внешние ссылки | Открываются в системном браузере, а не внутри окна |

## Значок в трее

Иконка рисуется кодом в `icon.rs`: скруглённый квадрат фирменного синего с
белой молнией и сглаживанием по краям. Растровых файлов в репозитории нет.

Правая кнопка открывает меню: «Открыть LinguaRust», «Начать повторение»,
«Сохранить резервную копию», «Закрывать в трей вместо выхода» (с галочкой) и
«Выход». Левая кнопка возвращает окно.

Подпись значка показывает, сколько карточек ждёт повторения: страница
отправляет оболочке состояние через `POST /__app/status` не чаще раза в две
секунды, а окно обновляет подпись через `Shell_NotifyIcon`.

## Горячие клавиши

Системные клавиши регистрируются через `RegisterHotKey` и срабатывают независимо
от активного окна:

| Клавиши | Действие |
| --- | --- |
| `Ctrl+Alt+L` | открыть окно и начать повторение |
| `Ctrl+Alt+S` | сохранить резервную копию прогресса |
| `Ctrl+Alt+P` | свернуть или восстановить окно |

Внутри окна работает `Ctrl+K` — командная палитра. Занятые чужой программой
клавиши не мешают запуску: оболочка сообщает об этом в консоль и продолжает
работу.

## Запуск из исходников

Нужны Rust 1.94+ и WebView2 Runtime (на Windows 11 обычно установлен).

```powershell
cargo run --manifest-path desktop/Cargo.toml
```

## Release-сборка

```powershell
cargo build --release --manifest-path desktop/Cargo.toml
.\desktop\target\release\linguarust-desktop.exe
```

Ключи запуска:

```text
--autostart       открыть окно свёрнутым (так запускает автозапуск Windows)
--data-dir <DIR>  каталог для настроек и резервных копий прогресса
--version         показать версию
--help            показать справку
```

Node.js, Python и внешний сервер не нужны.

## Как устроено

```text
desktop/
├── Cargo.toml
├── src/
│   ├── main.rs      окно, геометрия, тема, цикл событий, drag & drop
│   ├── server.rs    локальный HTTP-сервер и мост /__app/*
│   ├── bridge.js    скрипт window.linguarustDesktop (вставляется в WebView)
│   ├── hotkeys.rs   системные горячие клавиши RegisterHotKey
│   ├── tray.rs      значок в трее, меню, режим «закрывать в трей»
│   ├── icon.rs      иконка приложения, нарисованная кодом
│   ├── dialog.rs    нативные диалоги и слот ответа окну
│   ├── win32.rs     ShowWindow/SetForegroundWindow: настоящее сворачивание
│   ├── appdata.rs   настройки и резервные копии в %APPDATA%\LinguaRust
│   ├── autostart.rs ветка реестра HKCU\...\Run
│   ├── cli.rs       разбор аргументов командной строки
│   └── util.rs      даты, время и запуск внешних программ
├── site/            офлайн-копия веб-версии
└── sync-site.ps1    обновление site из web/ и data/
```

При запуске поднимается локальный HTTP-сервер на случайном порту `127.0.0.1`
и в окно грузится `desktop/site/index.html`. Локальный origin нужен, чтобы
работали `fetch` к данным, `localStorage` и service worker: из `file://` Chromium
их блокирует.

### Мост `window.linguarustDesktop`

Скрипт `bridge.js` подставляется в WebView до загрузки страницы, поэтому сайт
видит объект с нативными возможностями. В обычном браузере объекта нет, и
приложение работает как статическая версия.

Каждый запрос к `/__app/*` подписан токеном запуска (`X-LinguaRust-Token`).
Случайный порт localhost доступен любому локальному процессу, а токен живёт
только внутри текущего окна.

| Действие | Запрос | Результат |
| --- | --- | --- |
| `POST`, `export-dialog` | `{payload}` | нативный диалог сохранения, ответ — путь |
| `POST`, `import-dialog` | — | нативный диалог открытия, ответ — имя и содержимое |
| `POST`, `status` | `{due, cards, focus}` | подпись значка в трее |
| `POST`, `close-to-tray` | — | переключить режим закрытия |
| `POST`, `attention` | — | мигнуть окном в панели задач |
| `GET`, `info` | — | версия, каталог данных, автозапуск, трей, горячие клавиши |
| `POST`, `backup` | `{payload}` | запись `progress.json` |
| `GET /__app/backup` | — | последняя копия |
| `POST /__app/export` | `{payload}` | файл в `exports\` |
| `POST /__app/autostart` | `{enabled}` | ключ реестра |
| `POST /__app/theme` | `{theme}` | тема заголовка окна |
| `POST /__app/print` | — | диалог печати WebView2 |
| `POST /__app/open-data-dir` | — | Проводник с каталогом данных |

Обратное направление: оболочка вызывает в странице
`window.linguarustDesktop.flushBackup()` (срочная копия по горячей клавише),
`window.__linguarustDrop({name, content})` и `window.__linguarustDropError(message)`
после перетаскивания файла. Страница отвечает событиями `linguarust:file`,
`linguarust:file-error` и `linguarust:backup-done`.

Запросы из потоков сервера попадают в окно через `EventLoopProxy`, поэтому
смена темы, автозапуск, печать и файлы применяются в UI-потоке.

## Файлы данных

```text
%APPDATA%\LinguaRust\
├── settings.json    размер, позиция окна, тема, автозапуск
├── progress.json    последняя резервная копия прогресса
├── exports\         файлы экспорта с датой в имени
└── webview\         профиль WebView2: localStorage, тема, service worker
```

`settings.json` и `progress.json` пишутся через временный файл и переименование,
поэтому оборванное закрытие не оставит обрезанный JSON.

Две детали, без которых прогресс не переживает перезапуск:

- **Фиксированный порт 47715.** Origin `http://127.0.0.1:<порт>` — это ключ
  `localStorage`; со случайным портом хранилище обнулялось при каждом запуске.
  Если порт занят, оболочка берёт следующий и пишет об этом в консоль.
- **Профиль WebView2 в каталоге данных.** По умолчанию wry создаёт его рядом с
  exe, то есть внутри `target/`, и `cargo clean` стирал бы прогресс сайта.

## Обновление веб-контента

Если менялись `web/`, `data/` или `static/style.css`, синхронизируй копию
desktop-сайта:

```powershell
.\desktop\sync-site.ps1
```

`desktop/site` намеренно хранится в репозитории: бинарник можно запускать из
`target/release`, не публикуя Node.js-файлы.
