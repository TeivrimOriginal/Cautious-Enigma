# LinguaRust

Сайт для изучения английского языка, написанный на Rust: карточки с интервальным
повторением **SM-2**, чтение текстов с переводом слова по клику, грамматические
упражнения с проверкой и статистика прогресса.

🌐 **Живая версия:** https://teivrimoriginal.github.io/Cautious-Enigma/

## Две версии проекта

| | Статическая (GitHub Pages) | Серверная |
| --- | --- | --- |
| Где работает | в браузере, без бэкенда | Axum + PostgreSQL |
| Где размещена | `teivrimoriginal.github.io` | Vercel (serverless) или Docker |
| Прогресс | `localStorage` этого браузера | профиль в подписанной cookie + база |
| Офлайн | да (service worker, PWA) | нет, нужен сервер |
| Что внутри | `web/` — `index.html`, `app.js` | `src/` — весь Rust-код |
| Данные | те же файлы из `data/` | те же файлы + PostgreSQL |

Обе версии используют один словарь, одни тексты и одни упражнения из `data/`
и один и тот же алгоритм SM-2. Статическая версия открывается по любой ссылке
и не требует ни базы, ни хостинга с сервером; серверная нужна тем, кому важны
общие аккаунты, настоящая история повторений и SQL-запросы.

## О проекте

Площадка с авторским учебным контентом: упражнения, материалы и подборки
для практики английского. Цель — сделать изучение языка наглядным
и интересным, а не ещё одной скучной таблицей правил.

Весь учебный контент делается самостоятельно, с упором на практику:
материалы пишутся так, чтобы до них можно было дойти от базовых тем
к свободному чтению и восприятию речи на слух.

Технически это портфолио-пример серверного приложения среднего уровня:
SSR без клиентского фреймворка, типизированные ошибки, транзакции в БД,
юнит-тесты алгоритма повторений и CI.

## Возможности

| Раздел | Что делает |
| --- | --- |
| **Карточки** | Слова с переводом и примером, интервальное повторение по SM-2, четыре оценки ответа («Опять» → «Легко»), фильтры, импорт и экспорт CSV, защита от дублей |
| **Словарь** | 340 слов EN→RU с примерами, поиск по обоим языкам, «слово дня», озвучивание, добавление в карточки в один клик |
| **Чтение** | 4 текста уровней A2–B2, клик по слову → перевод (в том числе фразы из двух слов и словоформы) → добавление в карточки |
| **Грамматика** | 27 упражнений по темам, проверка ответа через JSON API с объяснением ошибки |
| **Экзамен** | 10 смешанных вопросов EN→RU и RU→EN на 90 секунд, разбор ошибок, +8 XP за верный ответ |
| **Тренажёр письма** | Перевод показан — слово нужно написать самому; регистр не важен, «to» можно опустить, +6 XP |
| **Статистика** | Стрики (текущий и рекорд), точность, активность по дням, стадии освоения, **слабые слова** и режим их тренировки |
| **Интерфейс** | Тёмная тема (следует за системной), PWA с офлайн-режимом, горячие клавиши, произношение слов, экспорт/импорт прогресса |
| **Прогресс** | XP и уровни (Новичок → Мастер), дневная цель, серия правильных ответов (комбо), 12 достижений |
| **Прогноз** | Симуляция SM-2 на 14 дней вперёд: сколько слов будет в работе и сколько повторений понадобится |
| **Профиль** | Вход по имени без пароля: UUID в подписанной cookie, история привязана к профилю |

## Стек

- **Axum 0.8** — HTTP-роутер и middleware
- **SQLx 0.9** — PostgreSQL, встроенные миграции, транзакции
- **Askama 0.16** — server-side рендер шаблонов
- **PostgreSQL** — хранение данных (Neon в production, Docker локально)
- **Vercel Rust runtime (`vercel_runtime` 2.x)** — serverless-деплой всего сайта одной функцией
- **tracing** — логирование, `thiserror` — типизированные ошибки

Клиентский JavaScript — около 150 строк без зависимостей: перевод по клику и
проверка грамматики. Повторение карточек работает вообще без JS
(`<details>` + обычные submit-кнопки).

## Быстрый старт

Нужен только Docker:

```bash
cp .env.example .env          # задайте COOKIE_KEY
docker compose up --build
# сайт: http://localhost:3000
```

Без Docker (нужны Rust 1.94+ и PostgreSQL):

```bash
cp .env.example .env          # укажите DATABASE_URL и COOKIE_KEY
cargo run
```

Миграции применяются автоматически при старте, словарь и тексты загружаются
в базу при первом запуске.

## Переменные окружения

| Переменная | Обязательна | Назначение |
| --- | --- | --- |
| `DATABASE_URL` | да | Строка подключения к PostgreSQL |
| `COOKIE_KEY` | в production | 128 hex-символов, ключ подписи cookie профиля |
| `BIND_ADDR` | нет | Адрес локального сервера, по умолчанию `127.0.0.1:3000` |
| `DATABASE_MAX_CONNECTIONS` | нет | Размер пула, на Vercel по умолчанию 2 |
| `RUST_LOG` | нет | Фильтр логов, по умолчанию `linguarust=info` |

Сгенерировать ключ:

```bash
python -c "import secrets; print(secrets.token_hex(64))"
```

## Тесты

```bash
cargo test
```

35 тестов: 27 юнит-тестов, 2 интеграционных и 6 тестов маршрутов. Юнит-тесты
покрывают самые важные куски логики:
- **SM-2** — интервалы 1/6 дней, рост интервала, сброс после ошибки,
  нижняя граница фактора лёгкости 1.3, прижатие некорректных оценок;
- **Статистика** — стрик сегодня/вчера, обрыв стрика, рекордная серия,
  точность, стадии освоения;
- **Словарь** — разбор TSV, регистр и пунктуация, словоформы
  (`deadlines → deadline`, `boiling → to boil`), отсутствие дублей;
- **Конфигурация** — разбор hex-ключа cookie.

Интеграционные тесты работают с настоящей PostgreSQL и проверяют путь
«профиль → карточка → повторение → статистика → удаление». Без базы они
пропускаются, чтобы `cargo test` оставался зелёным в CI:

```bash
DATABASE_URL=postgres://linguarust:linguarust@localhost:5432/linguarust \
  cargo test --test integration -- --nocapture
```

Тесты маршрутов (`tests/routes.rs`) базы не требуют: гостевые страницы,
404, валидация JSON API и `/healthz` проверяются через `tower::ServiceExt`.

## Алгоритм SM-2

Оценка ответа `q` лежит в диапазоне 0..5 (в интерфейсе используются 1, 3, 4, 5):

- `q ≥ 3` — успех: первый интервал 1 день, второй 6 дней, далее
  `интервал × фактор лёгкости`;
- `q < 3` — забыто: серия сбрасывается, повтор завтра;
- фактор лёгкости: `EF' = EF + 0.1 − (5 − q) × (0.08 + (5 − q) × 0.02)`, не ниже 1.3.

Реализация — `src/sm2.rs`, чистая функция без зависимостей от БД.

## Игровые механики

Общие для обеих версий: логика описана один раз в `src/stats.rs` (с тестами)
и продублирована в `web/app.js`.

| Действие | Опыт |
| --- | --- |
| Повторение с оценкой 3–5 | +10 XP |
| Повторение с ошибкой | +2 XP |
| Новая карточка | +5 XP |
| Правильный ответ в грамматике | +15 XP |
| Неправильный ответ | +3 XP |

- **Уровни** — 100 XP до первого уровня, далее на 50 XP дороже.
  Названия: Новичок → Ученик → Практик → Знаток → Продвинутый → Мастер.
- **Дневная цель** — 10, 20 или 50 повторений в день; в серверной версии
  хранится в профиле (`profiles.daily_goal`).
- **Комбо** — серия правильных ответов подряд; рекорд сессии сохраняется.
- **Достижения** (12): первые карточки, 10 и 100 слов, 50 и 200 повторений,
  неделя и месяц подряд, точность 90%, серия из 10, 20 правильных ответов
  в грамматике, «из сложного в простое».
- **Прогноз освоения** — прогон SM-2 на копии карточек: «через 14 дней в работе
  будет N слов, понадобится M повторений». Реальные данные не меняются.
- **Напоминания** (статическая версия) — браузерное уведомление в выбранное
  время, если есть карточки к повторению.

## Структура проекта

```
api/axum.rs           serverless-функция для Vercel
web/                  статическая версия сайта (GitHub Pages): страница,
                      скрипт, service worker, иконка, манифест
tests/integration.rs  интеграционные тесты с PostgreSQL
src/
  lib.rs              сборка роутера, общее состояние, встроенные стили
  main.rs             локальный HTTP-сервер
  auth.rs             профиль без пароля: подписанная cookie
  config.rs           конфигурация из переменных окружения
  db.rs               пул соединений, встроенные миграции
  error.rs            типизированные ошибки + HTML/JSON-ответы
  models.rs           строки базы данных
  queries.rs          SQL-запросы приложения
  routes/             HTTP-обработчики: home, cards, reading, grammar, stats, api
  seed.rs             словарь, тексты, упражнения
  sm2.rs              алгоритм интервального повторения
  stats.rs            стрики, точность, стадии освоения
migrations/           SQL-миграции
data/                 словарь (TSV), тексты и упражнения (JSON)
templates/            шаблоны Askama
static/               стили и скрипт (встраиваются в бинарник)
```

## Деплой

### GitHub Pages (по умолчанию)

Каждый пуш в `main` запускает `.github/workflows/pages.yml`: он собирает папку
`web/`, добавляет `data/` и `static/style.css` и публикует сайт по адресу
`https://teivrimoriginal.github.io/Cautious-Enigma/`. Никаких секретов и
переменных окружения не требуется.

### Vercel (серверная версия)

Репозиторий уже содержит `vercel.json`: любой путь перенаправляется на
`/api/axum`, поэтому весь сайт — одна serverless-функция.

1. Создайте базу в [Neon](https://neon.tech) и скопируйте `DATABASE_URL`.
2. Импортируйте репозиторий в Vercel (Git → Import Project).
3. Задайте переменные окружения: `DATABASE_URL`, `COOKIE_KEY`, `RUST_LOG`.
4. Deploy. При каждом пуше в `main` Vercel пересобирает проект сам.

Миграции применяются на холодном старте функции, поэтому отдельный шаг не нужен.

### Docker

```bash
docker build -t linguarust .
docker run -p 3000:3000 -e DATABASE_URL=... -e COOKIE_KEY=... linguarust
```

`docker-compose.yml` поднимает приложение вместе с PostgreSQL.
