# LinguaRust

Сайт для изучения английского языка, написанный на Rust: карточки с интервальным
повторением **SM-2**, чтение текстов с переводом слова по клику, грамматические
упражнения с проверкой и статистика прогресса.

🌐 **Статическая демоверсия:** https://teivrimoriginal.github.io/Cautious-Enigma/
<br>🏠 **Локальный сервер:** `http://127.0.0.1:3000`

## Запуск локально — основной режим

Серверная версия запускается на своём компьютере или в Docker и поддерживает
регистрацию, вход, гостевой режим и постоянное хранение прогресса в PostgreSQL.

### Docker Compose

Нужен только Docker:

```bash
cp .env.example .env          # Windows PowerShell: Copy-Item .env.example .env
# Для локального запуска достаточно ключа-заглушки из .env.example.
docker compose up --build
```

Откройте <http://localhost:3000> и выберите один из сценариев:

- **Создать аккаунт** — логин из 3–32 латинских символов и пароль от 8 символов;
  пароль хранится только как Argon2id-хеш, а браузер получает HttpOnly cookie
  с непрозрачным токеном серверной сессии;
- **Продолжить как гость** — быстрый вход по имени без пароля; прогресс также
  сохраняется в базе, пока жива сессия браузера.

### Cargo + PostgreSQL

Нужны Rust 1.94+ и доступная PostgreSQL:

```bash
cp .env.example .env          # Windows PowerShell: Copy-Item .env.example .env
# В .env укажите DATABASE_URL и при необходимости замените COOKIE_KEY.
cargo run
```

По умолчанию сервер слушает `127.0.0.1:3000`. Миграции применяются автоматически
при старте, словарь, тексты и упражнения загружаются при первом запуске.
Остановить сервер можно сочетанием `Ctrl+C`.

Для локальной базы из Docker Compose:

```bash
docker compose up -d db
$env:DATABASE_URL = "postgres://linguarust:linguarust@localhost:5432/linguarust" # PowerShell
cargo run
```

## Мобильная версия Android

В папке `mobile/` находится нативная офлайн-версия для Android: Java, Android
Studio и Gradle, без внешних библиотек. Она использует общие файлы из `data/`,
SM-2, локальное хранилище `SharedPreferences`, историю повторений карточек,
переключатель русского/английского интерфейса, сравнение карточек, экзамен,
библиотеку карточек, настраиваемую дневную цель и тренажёр письма.

Открой именно папку `mobile` в Android Studio или собери APK:

```powershell
cd mobile
$env:JAVA_HOME = "D:\12344\jbr"
$env:ANDROID_HOME = "C:\Users\teivrim\AppData\Local\Android\Sdk"
.\gradlew.bat :app:assembleDebug
```

APK: `mobile/app/build/outputs/apk/debug/app-debug.apk`. Подробная инструкция
по USB-установке находится в [`mobile/README.md`](mobile/README.md).

## Десктопное приложение Windows

В папке `desktop/` находится нативное окно на Rust + WebView2. Оно запускает
ту же офлайн-версию сайта через встроенный локальный HTTP-сервер: Node.js и
внешний сервер не нужны.

Сверх браузерных возможностей оболочка добавляет:

- резервные копии прогресса в `%APPDATA%\LinguaRust` с автоматическим
  восстановлением при пустом профиле;
- экспорт в файл с датой в имени и открытие папки данных в Проводнике;
- автозапуск вместе с Windows (ключ `HKCU\...\Run`, старт свёрнутым);
- запоминание размера, позиции и развёрнутого состояния окна;
- заголовок окна, который повторяет тему приложения;
- командную палитру `Ctrl+K` с переходами и нативными действиями.

Запросы веба к нативным возможностям идут через локальный сервер и подписаны
токеном запуска, а в браузере мост отсутствует — статическая версия продолжает
работать без изменений.

```powershell
cargo run --manifest-path desktop/Cargo.toml
# или release:
cargo build --release --manifest-path desktop/Cargo.toml
.\desktop\target\release\linguarust-desktop.exe
```

Подробности и синхронизация контента: [`desktop/README.md`](desktop/README.md).

## Две версии проекта

| | Статическая (GitHub Pages) | Серверная (основная локальная) |
| --- | --- | --- |
| Где работает | в браузере, без бэкенда | Axum + PostgreSQL на своём сервере |
| Прогресс | `localStorage` этого браузера | PostgreSQL: аккаунт или гостевая сессия |
| Регистрация | нет (демо-версия) | логин + пароль, Argon2id, сессии в БД |
| Офлайн | да (service worker, PWA) | нет, нужен запущенный сервер |
| Что внутри | `web/` — `index.html`, `app.js` | `src/` — весь Rust-код |
| Данные | те же файлы из `data/` | те же файлы + PostgreSQL |

Статическая версия остаётся удобной демонстрацией и офлайн-PWA. Для аккаунтов,
общей истории и SQL-функций используйте серверную версию.

## О проекте

Площадка с авторским учебным контентом: упражнения, материалы и подборки
для практики английского. Цель — сделать изучение языка наглядным
и интересным, а не ещё одной скучной таблицей правил.

Весь учебный контент делается самостоятельно, с упором на практику:
материалы пишутся так, чтобы до них можно было дойти от базовых тем
к свободному чтению и восприятию речи на слух.

Технически это портфолио-пример серверного приложения среднего уровня:
SSR без клиентского фреймворка, типизированные ошибки, транзакции в БД,
юнит-тесты алгоритма повторений и CI.

## Возможности

| Раздел | Что делает |
| --- | --- |
| **Карточки** | Слова с переводом и примером, интервальное повторение по SM-2, четыре оценки ответа («Опять» → «Легко»), фильтры, импорт и экспорт CSV, защита от дублей |
| **Словарь** | 340 слов EN→RU с примерами, поиск по обоим языкам, «слово дня», озвучивание, добавление в карточки в один клик |
| **Чтение** | 4 текста уровней A2–B2, клик по слову → перевод (в том числе фразы из двух слов и словоформы) → добавление в карточки |
| **Грамматика** | 27 упражнений по темам, проверка ответа через JSON API с объяснением ошибки |
| **Экзамен** | 10 смешанных вопросов EN→RU и RU→EN на 90 секунд, разбор ошибок, +8 XP за верный ответ |
| **Тренажёр письма** | Перевод показан — слово нужно написать самому; регистр не важен, «to» можно опустить, +6 XP |
| **Статистика** | Стрики (текущий и рекорд), точность, активность по дням, стадии освоения, **слабые слова** и режим их тренировки |
| **Интерфейс** | Тёмная тема (следует за системной), горячие клавиши, командная палитра `Ctrl+K`, произношение слов, адаптивная SSR-разметка |
| **Прогресс** | XP и уровни (Новичок → Мастер), дневная цель, серия правильных ответов (комбо), 12 достижений, защита стрика |
| **Прогноз** | Симуляция SM-2 на 14 дней вперёд: сколько слов будет в работе и сколько повторений понадобится |
| **Аккаунты** | Регистрация по логину и паролю, вход/выход, HttpOnly-сессии с TTL 30 дней и гостевой режим |

## Стек

- **Axum 0.8** — HTTP-роутер и middleware
- **SQLx 0.9** — PostgreSQL, встроенные миграции, транзакции
- **Askama 0.16** — server-side рендер шаблонов
- **Argon2id** — хеширование паролей; в базе никогда не хранится открытый пароль
- **PostgreSQL** — хранение данных (Neon в production, Docker локально)
- **Vercel Rust runtime (`vercel_runtime` 2.x)** — опциональный serverless-деплой
- **tracing** — логирование, **thiserror** — типизированные ошибки

Клиентский JavaScript на серверной версии небольшой и без зависимостей: перевод
по клику и проверка грамматики. Повторение карточек работает вообще без JS
(`<details>` + обычные submit-кнопки).

## Переменные окружения

| Переменная | Обязательна | Назначение |
| --- | --- | --- |
| `DATABASE_URL` | да | Строка подключения к PostgreSQL |
| `COOKIE_KEY` | в production | 128 hex-символов; нужен для миграции старой гостевой cookie |
| `BIND_ADDR` | нет | Адрес локального сервера, по умолчанию `127.0.0.1:3000` |
| `DATABASE_MAX_CONNECTIONS` | нет | Размер пула, на Vercel по умолчанию 2 |
| `RUST_LOG` | нет | Фильтр логов, по умолчанию `linguarust=info` |

Сгенерировать ключ:

```bash
python -c "import secrets; print(secrets.token_hex(64))"
```

## Тесты

```bash
cargo test
```

Тесты без базы проверяют SM-2, статистику, словарь, конфигурацию, хеширование
паролей, формы регистрации/входа, 404 и `/healthz`. Интеграционные тесты с
настоящей PostgreSQL проверяют путь «профиль → карточка → повторение →
статистика → удаление». Без базы они пропускаются, чтобы `cargo test` оставался
зелёным в CI:

```bash
DATABASE_URL=postgres://linguarust:linguarust@localhost:5432/linguarust \
  cargo test --test integration -- --nocapture
```

Тесты маршрутов (`tests/routes.rs`) базы не требуют: гостевые страницы,
регистрация, вход, 404, валидация JSON API и `/healthz` проверяются через
`tower::ServiceExt`.

## Алгоритм SM-2

Оценка ответа `q` лежит в диапазоне 0..5 (в интерфейсе используются 1, 3, 4, 5):

- `q ≥ 3` — успех: первый интервал 1 день, второй 6 дней, далее
  `интервал × фактор лёгкости`;
- `q < 3` — забыто: серия сбрасывается, повтор завтра;
- фактор лёгкости: `EF' = EF + 0.1 − (5 − q) × (0.08 + (5 − q) × 0.02)`, не ниже 1.3.

Реализация — `src/sm2.rs`, чистая функция без зависимостей от БД.

## Игровые механики

Общие для обеих версий: логика описана один раз в `src/stats.rs` (с тестами)
и продублирована в `web/app.js`.

| Действие | Опыт |
| --- | --- |
| Повторение с оценкой 3–5 | +10 XP |
| Повторение с ошибкой | +2 XP |
| Новая карточка | +5 XP |
| Правильный ответ в грамматике | +15 XP |
| Неправильный ответ | +3 XP |

- **Уровни** — 100 XP до первого уровня, далее на 50 XP дороже.
  Названия: Новичок → Ученик → Практик → Знаток → Продвинутый → Мастер.
- **Дневная цель** — 10, 20 или 50 повторений в день; в серверной версии
  хранится в профиле (`profiles.daily_goal`).
- **Комбо** — серия правильных ответов подряд; рекорд сессии сохраняется.
- **Достижения** (12): первые карточки, 10 и 100 слов, 50 и 200 повторений,
  неделя и месяц подряд, точность 90%, серия из 10, 20 правильных ответов
  в грамматике, «из сложного в простое».
- **Прогноз освоения** — прогон SM-2 на копии карточек: «через 14 дней в работе
  будет N слов, понадобится M повторений». Реальные данные не меняются.
- **Напоминания** (статическая версия) — браузерное уведомление в выбранное
  время, если есть карточки к повторению.
- **Защита стрика** — каждая четвёртая полученная награда (максимум три) даёт
  «заморозку»: если пропущен ровно один день, стрик не обнуляется.

   db.rs               пул соединений, встроенные миграции
   error.rs            типизированные ошибки + HTML/JSON-ответы
   models.rs           строки базы данных
   queries.rs          SQL-запросы приложения
   routes/             HTTP-обработчики: auth, home, cards, reading, grammar, stats, api

## Публикация (опционально)

### Docker на своём сервере

```bash
docker build -t linguarust .
docker run -p 3000:3000 -e DATABASE_URL=... -e COOKIE_KEY=... linguarust
```

`docker-compose.yml` поднимает приложение вместе с PostgreSQL и сохраняет базу
в volume `linguarust-pg`.

### Vercel (серверная версия)

Репозиторий содержит `vercel.json`: любой путь перенаправляется на `/api/axum`,
поэтому весь сайт — одна serverless-функция.

1. Создайте базу в [Neon](https://neon.tech) и скопируйте `DATABASE_URL`.
2. Импортируйте репозиторий в Vercel (Git → Import Project).
3. Задайте `DATABASE_URL`, `COOKIE_KEY`, `RUST_LOG`.
4. Deploy. При каждом пуше в `main` Vercel пересобирает проект сам.

### GitHub Pages (статическое демо)

Каждый пуш в `main` запускает `.github/workflows/pages.yml`: он собирает папку
`web/`, добавляет `data/` и `static/style.css` и публикует сайт по адресу
`https://teivrimoriginal.github.io/Cautious-Enigma/`. Регистрация и серверные
сессии в статической версии не работают — это отдельное офлайн-демо.
