# История изменений

Все значимые изменения проекта. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.9.0] — 2026-09-25

### Добавлено

- **MobileVersion**: нативное Android-приложение на Java в папке `mobile/`.
- Офлайн-карточки с SM-2, XP, уровнями, дневной целью и серией дней.
- Словарь, грамматические упражнения, чтение и статистика в мобильном интерфейсе.
- Gradle Wrapper и Android Studio-проект для SDK 36.
- Скрипт `mobile/build-apk.ps1` и инструкция по установке APK через ADB.
- История повторений по каждой карточке: дата, успех/ошибка и XP.
- Переключатель русского и английского интерфейса с сохранением выбора.
- Сравнение двух карточек с переводом, примером, серией и интервалом.

## [0.8.0] — 2026-09-24

### Добавлено

- **Регистрация и вход** по логину и паролю с хешированием Argon2id.
- Непрозрачные серверные сессии в PostgreSQL: HttpOnly cookie, TTL 30 дней,
  выход удаляет сессию на сервере.
- Гостевой вход по имени сохранён для быстрого старта без пароля.
- Страницы `/register`, `/login`, `/account`, `/logout` и адаптивная навигация
  с именем пользователя.
- Скрипты `scripts/dev.ps1` и `scripts/dev.sh` для локального запуска через
  Docker Compose; локальный сервер стал основным сценарием README.

### Изменено

- Сессии больше не доверяют UUID из браузера: токен хранится в PostgreSQL,
  а пароль никогда не записывается в открытом виде.
- Старая подписанная cookie гостя поддерживается для плавной миграции.

## [0.7.0] — 2026-09-24

### Добавлено

- **Защита стрика**: каждая четвёртая награда даёт «заморозку» (максимум три).
  Если пропущен ровно один день, стрик не прерывается, а день отмечается
  защищённым. Число защит вычисляется на лету, а не хранится.
- **Плавный поток повторений**: после оценки обновляется только блок карточки,
  список карточек и позиция страницы не перерисовываются.
- **Клавиша Esc** — пропустить карточку (засчитывается как «забыто»).
- Счётчик защиты стрика в шапке (❄️) и пояснение в статистике.

## [0.6.0] — 2026-09-24

### Добавлено

- **Прогноз освоения на 14 дней**: симуляция SM-2 на копии карточек —
  сколько слов перейдёт в работу, сколько повторений понадобится.
  В серверной версии это чистая функция `stats::forecast` с тестами.
- **Напоминания о повторениях** (Notification API): включение по кнопке,
  выбор времени (18:00–21:00), уведомление при наличии карточек к повторению.
- Правильное склонение русских числительных («3 слова», а не «3 слов»).
- Анимация появления карточки и ответа при повторении
  (уважает `prefers-reduced-motion`).
- 4 новых юнит-теста на прогноз: рост освоения, учёт дат, неизменность входа.

## [0.5.0] — 2026-09-24

### Добавлено

- **Экзамен-режим**: 10 вопросов за 90 секунд, половина EN→RU и половина RU→EN,
  варианты ответа перемешиваются, после каждого ответа показывается правильный,
  в конце — счёт, время и разбор ошибок. Лучший результат запоминается.
- **Тренажёр письма**: показывается перевод, слово нужно написать самому;
  проверка без учёта регистра, «to boil» и «boil» считаются одним ответом.
- Оба режима дают XP и учитываются в достижениях.

## [0.4.0] — 2026-09-24

### Добавлено

- **Опыт и уровни**: награды за повторения, новые слова и грамматику;
  уровни от «Новичка» до «Мастера» с прогресс-баром.
- **Дневная цель**: 10, 20 или 50 повторений в день, отдельная полоса прогресса
  и состояние «цель выполнена».
- **Комбо**: серия правильных ответов подряд прямо на карточке, рекорд
  сохраняется между сессиями.
- **12 достижений** с датой получения и всплывающими уведомлениями.
- Миграция `0002_game_progress.sql`: журнал грамматики и `profiles.daily_goal`.
- Новые эндпоинты: `POST /api/goal`, журнал ответов в `POST /api/grammar/check`.
- 8 новых юнит-тестов на уровни, награды и достижения.

## [0.3.0] — 2026-09-24

### Добавлено

- **Тёмная тема**: переключатель в шапке, сохранение выбора, стартовая тема
  по системной настройке без вспышки светлого фона.
- **Слабые слова и режим тренировки**: статистика показывает слова с наибольшим
  числом ошибок, а кнопка «Тренировать» повторяет их вне обычной очереди.
- **Импорт и экспорт карточек в CSV** (разделители `;`, `,` и табуляция,
  BOM для корректного открытия в Excel).
- **Горячие клавиши** в статической версии: пробел — показать ответ,
  1–4 — оценка повторения, `/` — поиск по словарю, цифры — выбор варианта.
- **Произношение слов** через Web Speech API: кнопка 🔊 в словаре, карточках
  и окне перевода; работает офлайн.
- **Офлайн-режим (PWA)**: service worker, манифест, иконка, страница 404,
  `robots.txt`, `sitemap.xml`.
- **Фильтры списка карточек**: все / к повторению / новые / в работе.
- **Экспорт и импорт прогресса** в JSON — подстраховка от очистки данных браузера.
- **Страница словаря** с поиском по английскому и русскому.
- Четвёртый текст для чтения (B2) и 8 новых грамматических упражнений (всего 27).
- Поиск фраз из двух слов по клику в текстах (`alarm clock`).
- Тесты HTTP-маршрутов без базы (`tests/routes.rs`) и интеграционные тесты
  с PostgreSQL (`tests/integration.rs`).
- Страница ошибки 404 для неизвестных маршрутов серверной версии.
- CI: проверка форматирования, clippy, тестов и release-сборки.

## [0.2.0] — 2026-09-24

### Добавлено

- **Страница словаря**: поиск по английскому и русскому, отметка слов,
  уже добавленных в карточки, добавление в один клик.
- **Слово дня** на главной странице и в словаре — стабильный выбор по дню года.
- **Статическая версия сайта** для GitHub Pages.
- Четвёртый текст для чтения (B2) и 8 новых грамматических упражнений.
- Словарь расширен с 250 до 340 слов.
- Поиск фраз из двух слов по клику в текстах (`alarm clock`).
- Тесты HTTP-маршрутов без базы (`tests/routes.rs`) и интеграционные тесты
  с PostgreSQL (`tests/integration.rs`).
- Страница ошибки 404 для неизвестных маршрутов серверной версии.
- CI: проверка форматирования, clippy, тестов и release-сборки.

### Исправлено

- Клик по слову в тексте сначала ищет пару соседних слов, затем словоформу.
- Слово с дефисом и апострофом корректно разбивается в тексте.

## [0.1.0] — 2026-09-24

### Добавлено

- Первая рабочая версия: серверное приложение на Axum, SQLx и Askama.
- Карточки с интервальным повторением SM-2, чтение с переводом по клику,
  грамматические упражнения, статистика со стриками.
- Профили без паролей на подписанной cookie.
- Dockerfile и docker-compose с PostgreSQL.
- 25 юнит-тестов алгоритма, статистики, словаря и конфигурации.
